# MODULE 0 — Le métier de trader & la vérité du marché

## Pitch manager (30 secondes)

> Avant la technique : le **métier**, les **attentes réalistes**, et pourquoi 90 % des débutants échouent (process, pas « setup magique »).  
> Ce module filtre les profils « je veux gagner vite » et pose le contrat pédagogique TORINVEST.

## Objectifs pédagogiques (interne)

À l’issue du module, le client doit pouvoir :

1. Définir le trading comme **gestion du risque + exécution disciplinée**, pas prédiction.
2. Lister 3 **mensonges courants** (influenceurs, « win rate », lifestyle).
3. Expliquer la différence **investisseur / trader / scalpeur** sans confusion.
4. Accepter le **parcours guidé** (lots de 3) comme structure, pas punition.
5. Savoir ce que La Forge couvre (ICT/SMC, macro, XAU, pro) sur ~57 h.

# MODULE F1 — Participants & microstructure

## Pitch manager

> Qui sont les **makers/takers**, comment l’**order flow** et les **sweeps** créent les mouvements que tu crois « aléatoires ».  
> Base pour tout ICT/SMC : **liquidité** et **participants**.

## Objectifs pédagogiques

1. Nommer les participants : retail, institutionnels, HFT, banques, hedgers.
2. Expliquer **maker vs taker** et l’impact sur spread / liquidité.
3. Décrire un **sweep** / prise de liquidité (concept, pas trade).
4. Lire un carnet d’ordres simplifié (bid/ask, depth conceptuelle).
5. Relier microstructure → **pourquoi** les niveaux « tiennent » ou « break ».

## Structure suggérée — 12 sections

| # | Section | Contenu manager | Durée |
|---|---------|-----------------|-------|
| 1 | Rappel Module 0 | 2 min lien mindset | 3 min |
| 2 | Écosystème marché | Qui est dans le jeu | 8 min |
| 3 | Retail vs institution | Volume, horizon, objectifs | 8 min |
| 4 | Carnet d’ordres | Bid, ask, spread, depth | 10 min |
| 5 | Makers & takers | Limit vs market ; rebates | 8 min |
| 6 | Order flow | Flux d’ordres ; agression | 8 min |
| 7 | Liquidité | Profondeur, thin book, slippage | 8 min |
| 8 | Sweeps & stops | Pools de stops ; pourquoi sweep | 10 min |
| 9 | Manipulation retail narrative | « Ils savent où sont les stops » — nuancer | 8 min |
| 10 | XAU preview | Or = actif liquide, sessions — teaser F2 | 7 min |
| 11 | Quiz prep | Schéma participants → sweep | 5 min |
| 12 | Synthèse | Lien F2 XAUUSD | 5 min |

## Schéma oral (ascii pour live)

```
Institution cherche liquidité → prix va chercher stops / anciens highs
Retail voit "breakout" → souvent fin de mouvement court terme
```

## Quiz manager — 10 questions

1. Maker place typiquement… → **ordres limit**
2. Taker… → **ordre market / prise immédiate**
3. Sweep = → **prise rapide de liquidité à un niveau**
4. Spread élargi souvent quand… → **liquidité faible / news**
5. HFT contribue à… → **liquidité + volatilité micro**
6. Stops cluster → **zone de liquidité potentielle**
7. Order flow lit… → **qui agresse le carnet**
8. Institution trade souvent pour… → **hedge / allocation / pas « trader TikTok »**
9. Slippage = → **exécution pire que prix attendu**
10. Microstructure aide à… → **comprendre mouvements, pas prédire chaque tick**

## Exercice pratique (chart)

- **Replay** : marquer 1 sweep sur XAU ou EURUSD (session replay outil La Forge).
- Critère 70 % : identification correcte sweep + 1 phrase « qui a été liquidé ».

## Erreurs fréquentes

- Confondre **breakout retail** et **liquidity grab**.
- Croire que **tout** mouvement est manipulation — nuancer.
- Ignorer **spread** sur petit compte / heures creuses.

# MODULE F2 — XAUUSD — anatomie de l’or

> 90 % du parcours avancé TORINVEST utilise XAU comme **laboratoire**.

## Objectifs pédagogiques

1. Décrire **XAUUSD** (spot CFD vs futures — mention, détail en pro).

4. Lister drivers : real yields, risk-on/off, géopolitique.
